# 离场条件（跟踪止盈 + 止损状态机）

从进场价格开始，每个 tick 看到价格上升就记录 peak。当价格自 peak 回撤超过**止盈回撤阈值（trail）**时发出止盈离场警告，目标价定为 `peak × (1 − trail)`。如果用户没有点击"已离场"而是继续等待，分两种情况：

1. 价格又涨上去，超过了目标价：止盈离场警告消失；继续涨超过 peak 则回到正常上涨逻辑（更新 peak 继续观察）。
2. 价格继续跌：止盈离场警告保持，直到价格跌破进场价 → 止盈警告消失，进入止损监控；亏损达到止损线后发出止损离场警告。

止损判断：相对进场价亏损达到 **3%**（`EXIT_STOPLOSS_PCT`，可按个股覆盖）。

## 止盈回撤阈值（trail）的取值 —— ATR 自适应（v2 默认）

旧版全局默认 0.15% 的问题：A股个股日内噪音普遍在 0.5%~1.5%，0.15% 处于买卖价差与随机波动之内，
**几乎必然在进场后几分钟内触发**，警告失去信息量。

v2 默认改为 **ATR 自适应**（`EXIT_TRAIL_PCT` 留空时启用）：

```
base_trail = clamp( 0.9 × 日ATR%(14日, Wilder), 0.8%, 3.5% )
```

- 波动大的股票（日 ATR 3%）给 ~2.7% 的回撤空间；波动小的大盘股自动收紧。
- **浮盈分级收紧（ratchet）**：以 peak 相对进场价的最高浮盈计算
  - 浮盈 ≥ +3% → trail × 0.85
  - 浮盈 ≥ +6% → trail × 0.70
  - 浮盈 ≥ +10% → trail × 0.55
  - 赚得越多，锁得越紧；trail 永不低于 0.5%。
- 用户在"持仓 / 离场跟踪"面板手动保存数值后，该股 trail **固定**为所填值（不再自适应）；
  点击"恢复自适应"清除覆盖。
- `EXIT_TRAIL_PCT` 填了数字则所有未覆盖个股都固定用该值（不推荐）。

阈值的实证依据可在个股详情的"参数回测验证"面板查看：对本股做止盈回撤参数扫描（0.5%~8%），
对比各档位的收益/胜率/交易次数，通常 0.5% 档明显劣于 2%~5% 档。

## 人工干预与个股参数

- 止盈回撤与止损比例可在"持仓 / 离场跟踪"面板按个股修改，仅对该股生效；不填写的股票沿用全局默认（环境变量 `EXIT_TRAIL_PCT` / `EXIT_STOPLOSS_PCT`）。
- 报警发出后可点击"解除报警"：该次警告转为安静状态（不再置顶/变红/响铃），但离场状态机继续运行；当状态发生变化（例如警告消失后再次触发、或从止盈警告转入止损流程）时自动恢复提醒。修改个股指标也会重新激活提醒。
- 除状态机外，**决策层**还会做信号级离场提示：多项指标转弱（日内分<40、跌破VWAP、板块转弱、15分钟动量恶化等满足≥3项）时建议减仓，触发止盈警告且日内已走弱时建议直接落袋。
