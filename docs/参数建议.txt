第一层：个股实时趋势

每只股票实时计算：

price
pct_change
gap_pct
vwap
price_vs_vwap
ma_5 / ma_10 / ma_20
intraday_momentum
relative_volume
turnover_rate
amplitude
volatility
distance_to_limit_up
distance_to_limit_down
bid_ask_spread
order_book_imbalance

其中最核心的是：

趋势 = 价格相对 VWAP + 分钟级动量 + 成交量相对放大 + 板块强度

单看“股价上涨”没意义，要看是不是：

上涨 + 放量 + 站上VWAP + 所属板块同步走强 + 大盘环境不差
第二层：市场 regime

A股一定要有一个“市场状态判断”，比如分成：

强趋势市
震荡市
弱势市
题材情绪市
恐慌杀跌市
缩量无方向市

可以用这些计算：

沪深300 / 中证500 / 创业板指 / 科创50 走势
上涨家数 / 下跌家数
涨停数 / 跌停数
成交额变化
行业上涨比例
指数是否在VWAP上方
指数日内回撤

然后你的个股信号要受 regime 影响。

例如：

强趋势市：允许追随动量
震荡市：降低追高权重，重视VWAP回归
弱势市：只提示风险，不轻易给积极建议
题材情绪市：提高板块热度、涨停家数、连板高度权重
第三层：板块/题材强弱

A股里这个很重要。建议每只股票都绑定：

行业
概念
题材
同板块涨幅排名
板块成交额变化
板块内涨停数量
板块内强势股数量

你可以做一个简单的分数：

sector_score =
  板块涨幅排名 * 0.3
+ 板块成交额放大 * 0.25
+ 板块内上涨比例 * 0.2
+ 板块内涨停数量 * 0.15
+ 龙头股强度 * 0.1
