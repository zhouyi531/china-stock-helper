# 决策与评分体系（v2）

本文档是系统所有打分公式、权重与基准值的唯一参考。任何调整应先改这里、再改代码（`server/src/indicators/layer1.ts`、`decision/engine.ts`、`regime/layer2.ts`、`sector/layer3.ts`），并用测试（`server/test/`）与回测（`/api/backtest`）验证。

## 总览

```
第一层 个股
  ├─ 日内分 intraday_score (0-100)   ←  "现在是不是好时机"
  └─ 日线分 daily_score   (0-100)    ←  "这是不是好股票（趋势质量）"
       trend_score = 0.55×日内 + 0.45×日线

第二层 市场 regime（-100..100 强弱分 + 六种状态）
第三层 板块 sector_score (0-100，行业为主，概念为辅)

决策层 decision
  机会分 score = 0.30×日线 + 0.25×日内 + 0.20×板块 + 0.15×大盘归一 + 0.10×量能质量
  + 硬性闸门（恐慌市/落刀/空头结构/临近涨停…）
  + 7 项入场检查清单
  → action: 强买/可买/观望/持有/减仓/离场/回避
```

数据缺失时权重自动归一化（缺板块则其余四项按比例放大），并降低置信度。

## 日内分 intraday_score（基准 50，摆幅约 ±56）

| 因子 | 公式 | 幅度 |
| --- | --- | --- |
| 价对VWAP | `clamp(±3%)/3 × 12` | ±12 |
| 5分钟动量 | `clamp(±2%)/2 × 8` | ±8 |
| 15分钟动量 | `clamp(±3%)/3 × 4` | ±4 |
| 当日涨跌幅 | `clamp(±5%)/5 × 8` | ±8 |
| 盘口失衡 | `imbalance × 6` | ±6 |
| 量能确认 | `方向 × clamp(量比−1, −1, 2) × 5` | +10/−5 |
| 日内位置 | `(day_range_pos−50)/50 × 6` | ±6 |
| 缺口行为 | 高开2%+回落破开盘价 −4；高开守住 +2 | ±4 |
| 涨停磁吸 | 距涨停≤1.5% 且量比≥1.5 → +4 | +4 |
| 均线上下 | 价>MA5 ±2，价>MA20 ±2 | ±4 |

## 日线分 daily_score（基准 50，摆幅约 ±50；K线<20根时为 null）

| 因子 | 规则 | 幅度 |
| --- | --- | --- |
| 均线结构 | 价>MA5、MA5>MA10、MA10>MA20、价>MA60 各 ±2.5；完整多头/空头排列额外 ±2.5 | ±12.5 |
| MA20斜率 | 5日变化 `clamp(±3%)/3 × 6` | ±6 |
| MACD(12,26,9) | 红柱 ±5；柱放大/缩小 ±3；DIF正负 ±2（柱=2×(DIF−DEA)，同花顺口径） | ±10 |
| RSI14 (Wilder) | `(clamp(20..80)−50)/30 × 8`；>80 再 −4（过热）；<20 +2（超跌） | ±8 |
| 20日突破 | 已破前20日最高 +8；距离≤1% +5 | +8 |
| 60日位置 | `(pos−50)/50 × 5`；贴 60日低位(<8) 再 −4 | ±5 |
| 5日动量 | `clamp(±8%)/8 × 5` | ±5 |
| 量价配合 | 放量(≥1.2)上行 +5；放量下跌 −5；缩量(≤0.8)回调未破MA20 +3 | ±5 |

## 第二层 regime 强弱分

```
score = clamp(指数均涨幅,±5)×12          # ±60
      + (涨家占比−0.5)×80                 # ±40
      + clamp((VWAP上方指数数−n/2)×10)    # ±20
      + clamp((涨停−跌停)×0.3)            # ±20
      + clamp((MA20上方指数数−n/2)×8)     # ±16   ← v2 新增
      + clamp(成交额较昨日%/15,±1)×8      # ±8    ← v2 新增（按U型时段曲线折算全天）
```

状态判定阈值不变（强趋势/震荡/弱势/题材/恐慌/缩量），其中：

- 题材市additionally要求最高连板 ≥ 3（涨停≥60 且 ≥3×跌停）。
- 缩量市的成交额萎缩阈值从 −8% 调到 **−12%**（折算值有噪音）。
- 成交额对比基准：上证综指+深证综指昨日成交额之和；今日值按 U 型日内成交曲线折算到全天
  （9:45 直线外推会高估约3倍，U型曲线修正了这一点，同样用于个股量比的兜底估算）。

## 第三层 sector_score

权重不变（排名30% + 成交额分位25% + 上涨比例20% + 板块涨停数15% + 龙头强度10%），
v2 修复：板块涨停数此前**从未取到**（恒为null，权重被静默丢弃），现从涨停池(`getTopicZTPool`)
按行业归集，同时得到板块内最高连板数；概念板块也参与打分，个股取最强概念分供决策层使用。

## 决策层

### 机会分与置信度

- `score = 0.30×日线 + 0.25×日内 + 0.20×max(行业分,概念分) + 0.15×(regime+100)/2 + 0.10×量能质量`
- 量能质量(0-100)：量比≥1.2 加成（4倍饱和+30）；量比<0.9 减分；量比>8 −15（异常分歧）；换手3~15% +10、>25% −10、<1% −10；成交额≥5亿 +5、<1亿 −15。
- 置信度 = 可用数据权重×100 − 分歧罚分（组件分差>40 → −15），行情延迟时上限 40。

### 入场检查清单（前5项为核心）

1. 日线趋势向好：日线分 ≥ 55
2. 日内强势：日内分 ≥ 58 且价在 VWAP 上方
3. 放量配合：量比 ≥ 1.3
4. 板块走强：板块分 ≥ 55 或行业排名前 30%
5. 大盘配合：regime 分 ≥ −10 且非恐慌/弱势市
6. 非追高：当日涨幅 ≤7%、VWAP偏离 ≤4%、RSI ≤78、距涨停 >1.5%
7. 流动性：成交额 ≥1.5亿 且价差 ≤0.2%

### 行动判定（无持仓）

| 条件 | action |
| --- | --- |
| 机会分 ≥75 且核心清单 ≥4 项通过 | strong_buy 强买信号 |
| 机会分 ≥65 且核心清单 ≥3 项通过 | buy 可买入 |
| 机会分 ≥45 | watch 观望 |
| 其余 | avoid 回避 |

硬性闸门（优先级高于分数）：

- 当日跌幅 ≥6%（落刀）→ avoid
- 日线分 <40 且价在 MA20 下方（空头结构）→ avoid
- 恐慌市 → 最高 watch，机会分上限 45
- 弱势市 → 机会分 <75 的 buy 降为 watch
- 距涨停 ≤1% → 最高 watch（追涨停滑点/开板风险）
- 涨幅>7% / VWAP偏离>4% / RSI>80 → 最高 buy（不给强买）

### 行动判定（持仓中）

- 止损警告 → exit（纪律优先）
- 止盈警告 + 日内分<45 或转空 → exit；否则 → reduce（分批止盈）
- 跌破成本 → hold + 强警示
- 其余：≥3 项恶化信号（日内分<40 / 价低于VWAP1%+ / 日线分<45 / 板块分<40 / 15分钟动量<−1.5%）→ reduce，否则 hold

### 建议止损（新开仓）

`止损距离 = clamp(1.8 × 日ATR%, 2%, 6%)`，挂在决策卡与AI提示中。比固定3%更合理：
低波动股不会被一倍噪音扫掉，高波动股不会给过大空间。

## 时机提示（entry hint）

- 10:00 前：开盘波动大、量比未稳定，等确认。
- 14:45 后：日内策略不开新仓；隔日策略看强势收盘。
- 日线强 + 日内弱：等回踩 VWAP 企稳或重新放量站上 VWAP。
- 位置偏高：勿追，等缩量回踩。
- 条件齐备：回踩 VWAP 不破或放量突破日内高点进场。

## 参数验证（回测）

`GET /api/backtest/:symbol?strategy=ma|breakout&trail=0.04&stop=0.03`

- 入场：均线多头启动（收盘>MA5>MA10 且 >MA20，且为新出现）或 20日新高放量突破（量>1.3×20日均量）。
- 出场：跟踪止盈（按日高更新peak、按日低触发）、硬止损（开盘跳空按开盘价成交）、收盘跌破MA10信号离场。
- 含 0.2% round-trip 摩擦成本；次日开盘成交；自带止盈回撤参数扫描（0.5%~8%）。
- 用途：**对比参数相对优劣**（如证明 0.15% trail 劣于 2~5%），不是预测绝对收益。

## 已知局限

- 回测为日线粒度，无法精确模拟日内路径（先到高点还是先到止损）。
- 板块涨停数依赖东财涨停池接口，海外IP可能降级。
- 决策层为规则系统，不含机器学习；阈值由经验+回测设定，应定期用回测面板复核。
